# verbecc-java

[![Java CI](https://github.com/bretttolbert/verbecc-java/actions/workflows/ci.yml/badge.svg)](https://github.com/bretttolbert/verbecc-java/actions/workflows/ci.yml)

A Java 25 rewrite of the XML-backed, non-ML conjugation core of
[Verbecc](https://github.com/bretttolbert/verbecc).

Supports Catalan (`ca`), Spanish (`es`), French (`fr`), Italian (`it`),
Portuguese (`pt`), and Romanian (`ro`). There are no runtime dependencies
outside the JDK, no models, and no Python process or installation is required.

## Build and test

Install a JDK 25 and set `JAVA_HOME` if necessary. The checked-in Gradle 9.2.1
wrapper downloads its checksum-verified distribution on first use; a system
Gradle installation is not needed. Build scripts use the Groovy DSL.

```sh
./gradlew build
```

On Windows, use `gradlew.bat build`.

The build produces the library, sources, and Javadoc JARs in `build/libs/`.
JUnit is a test-only dependency. The library JAR includes all twelve original
XML data files and the applicable license notices.

### GitHub Actions

[Java CI](.github/workflows/ci.yml) runs on pushes, pull requests, and manual
dispatches. It uses Temurin JDK 25 and the Gradle wrapper to run
`./gradlew clean build --no-daemon`, covering compilation, tests, Javadocs, and
JAR packaging. Gradle setup caches build dependencies and validates the wrapper.

Workflow runs retain test reports (including on build failure) and, after a
successful build, the library, sources, and Javadoc JARs as downloadable
artifacts for 14 days. CI does not publish releases or require repository secrets.

## Usage

```java
import io.github.bretttolbert.verbecc.CompleteConjugator;
import io.github.bretttolbert.verbecc.Language;

var french = new CompleteConjugator(Language.FR);

var present = french.conjugateMoodTense("manger", "indicatif", "présent");
System.out.println(present.getFirst().forms()); // [je mange]

var perfect = french.conjugateMoodTense("manger", "indicatif", "passé-composé");
System.out.println(perfect.getFirst().forms()); // [j'ai mangé]

var reflexive = french.conjugateMoodTense("se lever", "indicatif", "présent");
System.out.println(reflexive.getFirst().forms()); // [je me lève]

var complete = french.conjugate("aller");
var tenses = complete.moods().get("indicatif");
System.out.println(tenses.keySet());

// Omit subject pronouns and subjunctive conjunctions, retaining inflection metadata.
var bare = french.conjugateMoodTense("manger", "indicatif", "présent", false);
System.out.println(bare.getFirst().forms()); // [mange]

var spanish = new CompleteConjugator("es");
System.out.println(spanish.conjugateMoodTense("tener", "indicativo", "presente"));
```

Mood and tense keys use the localized names from the Python implementation,
lowercased, including its spellings (for example Spanish `participo` and
French `imperatif`). `conjugate(infinitive).moods()` exposes the available keys.
The same optional `conjugatePronouns` boolean is available on `conjugate` and
`conjugateMood`.

Each immutable `Conjugation` record contains:

- `person()`: `FIRST`, `SECOND`, or `THIRD`.
- `number()`: `SINGULAR` or `PLURAL`.
- `gender()`: `MASCULINE` or `FEMININE` when applicable.
- `pronoun()`: the associated subject pronoun, even when not printed.
- `forms()`: the primary conjugation and all alternate spellings.

Inapplicable grammatical fields are `null`, such as person and pronoun for a
participle. Multiple records may share a pronoun where compound participles
have different gender agreement. Non-applicable XML forms represented by `-`
remain `-`; empty XML person slots are omitted without shifting other persons.
Dictionary translations and aspirate-H metadata are available on `Verb`.

`getInfinitives()`, `getVerbs()`, `findVerbByInfinitive()`,
`getTemplateNames()`, and `getVerbsThatStartWith(query, maxResults)` expose
the dictionary. Exact accented spelling takes precedence; lookup and prefix
search also accept unaccented spelling. Inputs are case-insensitive; full
verb/mood/tense inputs are normalized to Unicode NFC.

Parsed dictionaries are cached per language. Conjugator instances and returned
collections are immutable/thread-safe.

### Android

The sibling `verbecc-android` application includes this project through a Gradle
composite build, so library changes are rebuilt automatically. Android apps must
enable core library desugaring (`com.android.tools:desugar_jdk_libs:2.1.5` or newer)
for the Java collection and string APIs on older Android releases. The library
still builds with JDK 25; Android's D8 handles records and the generated bytecode.
The XML loader uses SAX (Android DOM rejects accented XML tag names) and rejects
external resource resolution, while retaining the bundled dictionaries' internal DTDs.

From `verbecc-android`, run `./gradlew assembleDebug` to build the application.
Its Compose screen accepts an infinitive and one of the six languages, then
displays all returned moods, tenses, pronouns, and alternate forms offline.
Conjugation runs off the UI thread; unknown verbs and dictionary errors are shown
explicitly. Run `./gradlew connectedDebugAndroidTest` with an emulator connected
to verify the library and screen on Android.

## Scope and compatibility

- Simple tenses use the XML stems and endings, including alternates, Catalan
  stem deletions, and `modify-stem="strip-accents"`.
- Compound tenses use the Python inflectors' auxiliary maps, including
  French/Italian participle agreement and Romanian future/conditional forms.
- All source pronouns are retained, including Spanish `vos`, `usted`, and
  `ustedes`, and French `on`. Spanish voseo uses the source's default
  Rioplatense transformations; other regional options are not implemented.
- French, Spanish, Italian, and Portuguese reflexive forms follow the source
  inflectors, including their imperative suffix conventions. Reflexive-only
  dictionary entries can use their own templates when no plain entry exists.
  With subject pronouns disabled, reflexive clitics are still retained.
- As in the Python inflectors, Catalan has no generated compound tenses;
  Catalan and Romanian do not recognize reflexive infinitive syntax.
- Romanian conditional forms are included in complete results even though the
  XML has no conditional mood; their definitions come from the Python code.
- Unknown verbs throw `VerbNotFoundException`. Blank inputs, invalid moods,
  invalid tenses, and negative search limits throw `IllegalArgumentException`.
  There is no prediction or suffix-based guessing of unknown verbs.
- XML is copied **byte-for-byte**, not corrected or regenerated. Some source
  entries have inconsistent infinitive/template suffixes; these throw
  `IllegalStateException` with the offending mapping rather than silently
  guessing. Duplicate template names resolve to the first definition, matching
  the Python lookup. `getTemplateNames()` lists unique names.
- This is a Java API, not a port of Python's ML, configuration, localization
  enums, JSON/YAML formatting, or internal class hierarchy.

## Verification

The tests include 298 expected-output cases migrated from the Python language
tests, Java-specific coverage of compound/reflexive forms and API behavior,
representative verbs for referenced templates with matching suffixes, and
SHA-256 checks for all twelve copied XML files. First-form-only Python tests
remain first-form-only; tests of alternate forms compare all alternatives.

```sh
./gradlew test
```

No sibling checkout or Python environment is needed to run the tests.
